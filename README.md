# 扶養収入チェッカー

アルバイト・インターン収入を月ごとに記録し、扶養手当の管理ライン（初期値：年間150万円）に対して
「今いくら／あといくら／あと何時間働けるか」を一瞬で確認できる、個人利用のスマホファーストWebアプリです。

> ⚠️ このアプリは収入管理・シミュレーションのためのツールです。「年額150万円以上の恒常的な所得があると見込まれるか」という
> 実際の扶養認定は勤務先・保険者の判断によります。本アプリの表示だけで扶養から外れる／外れないと断定しないでください。

## 主な機能

- ホーム：直近12か月（任意の基準月を選択可）の対象収入・残額・残り稼働時間・進捗バー・危険度表示
- 月別収入管理：月ごとの勤務先別収入とその他収入を編集・追加・削除
- シミュレーション：勤務時間→収入をリアルタイム計算（単発 / 複数月の勤務予定）、実績への反映
- グラフ：勤務先別の積み上げ棒グラフ＋累積収入の折れ線＋150万円基準線、直近12か月区間のハイライト
- 3か月連続チェック：月額注意ライン（初期値125,000円）以上が連続注意月数（初期値3か月）続いた場合に警告
- 設定：管理ライン・月額注意ライン・連続注意月数・勤務先ごとの時給を変更可能
- データのバックアップ：JSON書き出し／読み込みで機種変更にも対応
- ダークモード・レスポンシブ対応

## 起動方法

```bash
npm install
npm run dev
```

`http://localhost:5173` をiPhoneなど同一ネットワーク上の端末からアクセスする場合は `npm run dev -- --host` を使ってください。

## ビルド・チェック

```bash
npm run build      # TypeScriptチェック + 本番ビルド
npm run lint        # oxlintによる静的解析
npm test            # 計算ロジックのユニットテスト（Vitest）
```

## デプロイ方法（Vercel）

本プロジェクトは静的ビルド（Vite）のため、Vercelにそのままデプロイできます。

```bash
npm i -g vercel   # 未インストールの場合
vercel             # 初回：プロジェクトをリンク
vercel --prod      # 本番デプロイ
```

Build Command: `npm run build` / Output Directory: `dist` （Vercelが自動検出します）

## データ保存方法

- すべてのデータ（月別収入・時給・設定）はブラウザの `localStorage` に保存されます。サーバー・ログイン機能はありません。
- Safariを閉じて再度開いてもデータは保持されます。
- 設定画面の「初期データに戻す」で初期データにリセットできます（確認ダイアログあり）。
- 設定画面の「データを書き出す／読み込む」でJSON形式のバックアップ・復元ができ、機種変更時にも利用できます。

## 計算方法

- 月合計 = 各勤務先の金額の合計 + その他収入（円単位の整数で計算し、浮動小数点誤差を避けています）
- 直近12か月の対象収入 = 選択した基準月を含む直近12か月分の月合計の合計
- 管理ラインまでの残額 = 管理ライン − 対象収入（負の場合は0）
- 超過額 = 対象収入 − 管理ライン（負の場合は0）
- 残り稼働時間 = 残額 ÷ 勤務先の時給（勤務先ごとに時給が異なる場合は個別に計算）
- 危険度：70%未満＝余裕あり／70〜90%未満＝注意／90〜100%未満＝かなり注意／ちょうど到達＝150万円到達／超過＝150万円超過
- 3か月連続チェック：月合計が月額注意ライン以上の月が暦の上で連続し、その長さが連続注意月数以上になった場合に警告を表示
